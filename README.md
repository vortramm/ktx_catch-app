# KTX 자동 예매 앱

매진된 KTX 취소표를 자동으로 찾아 예약해 주는 안드로이드 앱입니다.

## 설치하기

1. 폰에서 아래 링크를 누르면 설치 파일이 내려받아집니다.

   **👉 [최신 버전 내려받기](https://github.com/vortramm/ktx_catch-app/releases/latest/download/ktx_catch.apk)**

2. 내려받은 `ktx_catch.apk`를 엽니다.
3. "출처를 알 수 없는 앱" 설치를 허용하라고 나오면 **허용**을 누르고 설치합니다.
4. 앱을 열고 메뉴(⋮) → **코레일 로그인**에서 코레일톡 계정으로 로그인합니다.

## 업데이트

따로 할 일이 없습니다. 앱이 켜질 때 알아서 확인하고, 새 버전이 있으면 화면 맨 위에 안내가 뜹니다.
안내를 누르고 **설치**를 누르면 됩니다.

## 알아 두기

- 예약이 되면 알림이 울립니다. 결제는 **코레일톡 앱**에서 결제 기한 안에 하세요. 기한이 지나면 자동 취소됩니다.
- 화면을 꺼 두어도 계속 찾습니다. 오래 기다릴 때는 메뉴 → **배터리 최적화 해제**를 해 두세요.
- VPN을 켜 두면 코레일이 접속을 막을 수 있습니다.
